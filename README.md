# Spatial Propagation of Infrastructure Systems: An EO-Integrated SDM Framework for Transport Corridor Resilience

## Overview
This repository contains the complete analytical framework for quantifying infrastructure propagation within transport corridor systems using an Earth Observation–integrated Spatial Durbin Model (SDM). The study focuses on Tanzania's Standard Gauge Railway (SGR), Central Corridor, and Mtwara Development Corridor.
